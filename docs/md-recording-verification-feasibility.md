# MD 녹음 검증 및 곡 제목 변경 기능 검토

검토일: 2026-09-19

상태: 타당성 검토 완료, 구현 및 실기기 검증 전

## 결론

NetMD 또는 지원되는 Hi-MD 기기를 USB로 연결할 수 있다면, Album Deck의 재생 목록과 MD의 곡 수·순서·길이를 대조하고 일치하는 곡의 제목을 변경하는 기능은 구현 가능하다. 현재의 Edge 기반 웹앱, 로컬 Node.js 실행, Vercel 배포를 유지할 수 있다. ElectronWMD 전체를 합치기보다는 그 기반인 Web MiniDisc Pro 및 `netmd-js`의 필요한 장치 연결·목록 조회·제목 변경 부분을 통합하는 편이 범위가 작다.

단, 길이 비교는 녹음의 **구조적 일치 여부**만 판단한다. 같은 길이의 다른 곡, 무음으로 녹음된 곡, 짧은 음 끊김이나 음질 문제를 확인하지는 못한다. 화면에도 “녹음 성공 확정” 대신 “곡 수·순서·길이 일치”처럼 판정 근거를 표시해야 한다.

## 현재 코드에서 활용할 정보

- [Album Deck 재생 목록 구성](../web/app.js)은 앨범·플레이리스트에서 재생 가능한 곡을 골라 Spotify URI, 제목, 아티스트, `duration_ms`를 보유한다. Spotify의 [Track API](https://developer.spotify.com/documentation/web-api/reference/get-track)는 길이를 밀리초로 제공한다.
- 현재 재생 대기열은 페이지 메모리에 있다. MD 녹음 후에도 비교할 수 있도록 실제 재생 대상과 순서, 곡별 재생 결과, 시작·종료 시각, 설정한 곡간 무음, Spotify 컨텍스트를 별도의 녹음 기록으로 저장해야 한다. 조회만 했거나 재생에 실패한 곡은 기대 목록에 넣지 않는다.
- 기존 곡간 무음은 MD 레코더가 곡을 나누도록 돕지만, 실제 트랙 마크와 MD 곡 길이는 레코더의 동작 및 녹음 시작·종료 시점에 따라 달라질 수 있다.

## MD 접근 가능성

- 로컬 `D:\GIT\ElectronWMD\src\wmd\original\services\interfaces\netmd.ts`의 NetMD 서비스는 `listContent()`로 트랙의 순서·제목·초 단위 길이를 읽고 `renameTrack()`으로 제목을 변경한다. 쓰기 방지 여부에 따라 메타데이터 편집 가능 여부도 판정한다. Hi-MD 서비스에도 목록 조회와 제목 변경 기능이 있다. 원본 프로젝트는 [ElectronWMD](https://github.com/asivery/ElectronWMD)이다.
- [Web MiniDisc Pro](https://github.com/asivery/webminidisc)는 Chromium 브라우저의 WebUSB를 이용하며 Edge를 지원 대상으로 명시한다. 따라서 로컬 Edge 앱 창과 HTTPS인 Vercel 사이트 모두에서 **사용자 PC에 연결된** MD 기기를 브라우저가 직접 다루는 구조가 가능하다. Vercel 서버가 USB 장치에 접속하는 구조는 아니다. WebUSB는 [보안 컨텍스트](https://developer.mozilla.org/en-US/docs/Web/API/WebUSB_API)와 장치 접근 허가가 필요하다.
- Windows에서는 호환 USB 드라이버가 필요하다. 일반 MD 기기처럼 NetMD/지원 Hi-MD 인터페이스가 없다면 이 방식으로 디스크 목록을 읽거나 제목을 쓸 수 없다. 실제 지원 여부는 사용할 기기 모델과 디스크 모드로 시험해야 한다.
- 녹음이 끝나고 기기의 TOC가 반영된 다음 USB로 디스크를 읽는 흐름을 기본으로 한다. 녹음과 USB 제어를 동시에 수행할 수 있다는 가정은 하지 않는다.

## 권장 사용자 흐름

1. 녹음 시작 전에 디스크의 기존 트랙 목록을 저장하거나, 빈 디스크 사용을 안내한다. 재생 시작 시 실제 재생할 곡을 녹음 기록으로 남긴다.
2. 녹음이 끝난 뒤 사용자가 MD 녹음을 종료하고 NetMD/Hi-MD 기기를 연결한다. 앱은 디스크 목록을 새로 읽어 기존 곡과 새 곡을 구분한다.
3. 새 MD 트랙과 녹음 기록을 순서대로 대조한다. 곡 수가 다르거나 트랙이 누락·합쳐짐·분할됨으로 보이는 경우 해당 구간을 불일치로 표시한다. 길이 비교에는 사용자 조정 가능한 허용 오차를 적용하며, 초기값은 실기기 측정 후 정한다.
4. 예상 제목, MD의 현 제목, 양쪽 길이와 차이, 판정 이유를 보여준다. 확실하게 대응되는 항목만 제목 변경 후보로 선택하고 사용자가 미리보기를 확인하게 한다.
5. 쓰기 방지 및 장치 기능을 확인한 뒤 선택된 제목만 변경한다. 디스크를 다시 읽어 변경 결과를 확인하고 실패 항목은 별도로 표시한다.

## 구현상 주의점

- 단순히 두 목록의 같은 인덱스를 비교하면 한 곡이 빠졌을 때 이후 곡을 모두 잘못 이름 붙일 수 있다. 곡 수·순서·길이를 함께 사용해 누락·추가 트랙을 허용하는 정렬 방식이 필요하다. 낮은 신뢰도의 대응은 자동 변경 대상에서 제외한다.
- 길이 허용 오차는 MD의 트랙 마크 위치, 앞뒤 무음, 재생 전환 지연, SP/LP 모드에 따라 달라질 수 있다. 예시값을 고정된 정확도 보장처럼 취급하지 않는다.
- 표준 MD의 제목 문자 집합과 길이에는 제한이 있다. 특히 한글 Spotify 제목은 [`netmd-js`의 제목 변환](https://github.com/cybercase/netmd-js) 과정에서 제거되거나 변형될 수 있다. 변환 후의 실제 기록 예정 문자열을 미리 보여주고, 수정 또는 변경 건너뛰기를 허용해야 한다. Hi-MD의 메타데이터 처리와 구분한다.
- 길이만으로 실제 오디오 내용을 검증할 수 없다. 오디오 확인을 추가하려면 지원 기기의 트랙 다운로드나 별도 입력으로 녹음을 다시 받아 비교해야 하며, 이는 별도 범위다. [Web MiniDisc Pro](https://github.com/asivery/webminidisc)는 일부 기기에서 트랙 다운로드를 지원하지만 모델별 제약이 있다.
- ElectronWMD/Web MiniDisc Pro와 `netmd-js`는 GPL-2.0 계열이다. 공개 배포에 코드를 포함할 때는 해당 라이선스와 고지·소스 제공 방식을 검토해야 한다. [ElectronWMD](https://github.com/asivery/ElectronWMD), [`netmd-js`](https://github.com/cybercase/netmd-js).

## 먼저 검증할 최소 범위

1. 실제 MD 기기 모델과 디스크 모드에서 Edge의 WebUSB 연결, 디스크 목록·곡 길이 읽기, 쓰기 가능 여부 확인.
2. 테스트 디스크의 트랙 하나에 제목을 쓰고 다시 읽어 확인. 영문·한글 제목 변환 결과 확인.
3. 짧은 앨범 또는 플레이리스트를 실제 녹음해 Spotify 길이와 MD 길이의 차이, 곡 분리 및 예외 사례 측정.

이 세 단계가 통과하면 녹음 기록 저장, 목록 정렬·판정, 미리보기, 선택적 일괄 제목 변경 순으로 구현한다. 현재 저장소에는 아직 MD 제어 기능을 추가하지 않았다.
